## How I work

- **Typed, then checked by CI**: strict TypeScript, and a GitHub Actions build that stops on a type error before anything deploys.
- **Written down**: a repository opens with what it does, its result and how to reproduce it, with a pipeline figure where useful.
- **Small, reversible steps**: one change per commit with a plain imperative message; infrastructure kept as code in Terraform and Docker.
